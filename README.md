# Phishing Email Detection & Awareness Report

## Cyber Security Task 2 

### Project Overview

This project focuses on identifying phishing indicators in email communications and creating awareness about common phishing techniques used by attackers.

The assessment involved analyzing email samples, reviewing email headers, examining sender information, and classifying emails based on their risk level.

---

## Tools Used

* Google Message Header Analyzer
* MXToolbox Email Header Analyzer
* Web Browser
* Canva

---

## Analysis Approach

The following methodology was used during the assessment:

1. Collected phishing and legitimate email samples.
2. Analyzed email headers.
3. Reviewed sender addresses and domains.
4. Inspected email content and embedded links.
5. Checked SPF, DKIM, and DMARC authentication results.
6. Identified phishing indicators.
7. Classified emails as Safe or Phishing based on findings.
8. Developed phishing prevention and awareness guidelines.
